# Level creator

Add a playable Space Chicken level that no shipped level could be mistaken for. Read [the authoring reference](../level-creator/references/spacechicken.md), [the game critic](../game-critic/SKILL.md), and the working tree before editing. Do not deploy.

Creativity here is not a mood; it is three artefacts the critic scores. No artefact, no build: a level pitched as "like Level 8 but greener" is rejected before art starts.

## Inputs

Accept a `selection.json` from the selector or paths the user names. For version 1, read `level_id`, `decision_status`, `choices`, `unfilled_roles`, and `requested_revisions`. Resolve each `asset_path` from the selection file. A draft recommendation is not a choice. If the art is still ambiguous, ask once, and keep reading the level format while you wait. Do not quietly substitute a different paint.

A `paint.js` file is not a hazard yet. Use hazards that already run for the layout. Record concept actors that were not wired. Build a new actor only when the user asked for that actor in the level, and paint it with the painted-art rules.

## Design before code (the three artefacts)

Write these in the build report first and run the Concept critic (see [game-critic](../game-critic/SKILL.md)) before touching `levels/`:

1. **Novelty Ledger** — a table against the three nearest shipped levels (nearest by theme, gravity, and campaign position) with one row each for background devices, topology, signature mechanic, hazard pairing, and finale rule. The new level must differ in at least three rows, including topology and at least one of {signature mechanic, finale rule}. "Different colour" never counts as a row difference. The critic's `clone-suspect` / `background-recycled` checks enforce the ledger; do not argue with a flag by editing the ledger after the fact.
2. **Signature Mechanic Canvas** — one verb this level teaches that no sibling teaches the same way. Name the verb, the safe teach beat (first use, survivable), the press beat (combined with a known verb), the twist (finale form), and the tell. Examples already owned — do not re-teach them as your signature: bonk-spring chains (5), lift timing (10), beam-dark crossing (10/14), shield-wave clear (8), tram riding (14). Your canvas may reuse a hazard type, but the _decision_ it demands must be new (e.g. "shoot while falling", "wait on a moving deck under fire", "bonk to change a gate's state").
   **Classify and prove it.** Mark the signature `mandatory`, `optional`, or `visual metaphor` — honestly: a lift the route can walk past is optional, however the instructions phrase it. Add a **Signature proof** block: the runtime observable that shows the verb happening (lift-contact samples, bonk count, cargo state change, beat-phase crossing), and the **bypass test** — what a crown run that skips the signature does. A mandatory signature must fail, reroute, or visibly cost the bypass; if the bypass clears cleanly, the signature is optional and the brief says so. Renaming an existing system is not a mechanic: rescue cages renamed "samples" are still a time bonus unless the level implements acquire → carry state → delivery validation (crown without cargo has a defined response; collecting changes visible state; delivery completes it). Presence stills prove none of this — proof is telemetry, state, or motion capture from a real run.
3. **Topology Fingerprint** — one line naming the route shape and a sketch of its height profile. Banned as a fingerprint: `flat left-to-right line at one height` (that is the retired default, whatever the palette). Owned shapes to not copy wholesale: beachhead decks (8), fang shaft (9), glass stair (10), trench dip (11), marrow bridge (12), container stair (13), vent tower (14), pylon stair (15). Pick an unowned combination — descent, loop-back, split-rejoin, tower, sink-and-rise, bridge-cross, gauntlet rooms — and build the decks to match the sketch, not the other way round. For a contra-style level the sketch also names its **tiers** (the distinct height bands the player can stand and act on — ground, mid, high, and any shaft or pit line below ground) and where the route splits between them and rejoins; a contra fingerprint with one tier is `flat` however it is worded (see Stacked tiers and split paths below).
   **Geometry must match the words, measurably.** Before art polish, check the authored decks against the fingerprint and every batch sibling in coordinates, not adjectives: a `descent` ends its main line materially lower than it starts (crown deck below the opener, not a rise with a dip); a `loop-back` revisits an x-range at a second height on a demonstrated route; a `funnel` narrows its playable span act over act; a `tower` gains most of its height vertically in a short width. Record the numbers (start/crown deck heights, width, deck count, nearest sibling + `layoutSimilarity`) in the build report. The critic's `skeleton-rhyme` flag catches copied x-lists, but direction and shape claims are yours to verify — a rising route briefed as a plunge fails reconciliation even when every screenshot is pretty.

Sketch **three divergent layouts** on paper (different fingerprints, not three widths of one row), kill two with one-line reasons recorded in the build report, and build the survivor. Refining only the first idea you had is how clones happen.

## Author the level

Add a `levels/<name>.js` module and register it in `levels/index.js`. Set `NEXT_LEVEL` on the previous finale only when this level extends the campaign. A news level sets `content.news = { outlet, headline }` (real outlet and headline from the story — never invented) and stays out of the campaign chain; the marker puts it in `NEWS_LEVEL_IDS` and the title screen's NEWS LEVELS section automatically. A news brief that declares `Combat profile: contra` (a fight-shaped story; boss-themed stories usually do) is built contra-style despite staying out of the chain: `PHASER: true`, stacked floors under the contra rules below, the gun rack for its position, real boarder waves, and a crown encounter finale when the brief declares a boss theme. A news level without that declaration stays PHASER-off with a token wave. Add a `music/<id>.js` track and register it in `music/index.js` so the level does not fall through to level 1's track. Tracks and any new effect (one call site per game event, e.g. a themed telegraph tell) follow [the audio creator](../audio-creator/SKILL.md). Register both new files in `config/runtime-assets.cjs` `rootFiles`, or the local server 404s them and the Cloudflare build omits them.

Give it a title, gravity, world size, kill zone, start, and crown. Open with a readable jump, introduce one hazard, then stack ideas, and leave a rest before the crown. Every level ships at least one enemy actor placed on the route, and a themed brief's enemy must be that brief's themed actor, wired through the integrator — hazard-only levels with no enemy fail the brief. Vary the route: mix deck widths, heights, and at least three platform reads (wide deck, narrow perch, stair, bridge, shaft, or sloped-look set piece); a single repeated flat deck across the whole level is a draft, not a level. Copy _field shapes_ (keys, hazard entry syntax) from an existing level module — never its deck sequence, hazard sequence, or set-piece placement; the critic compares those sequences. A new background `type` needs a `create*BackgroundLayout` plus branches in `ensureLayout` and `drawLayer`. Bake height follows that level's world height. Keep `scrollFactorY` at 1.

**Weapons ship with something to shoot.** PHASER bolts only damage `boarder` and `boss` actors — drones, lasers, rollers, bonk enemies, and every other hazard are immune. The shipped roster holds a clean invariant: every PHASER level spawns boarders on the route, every PHASER-off level spawns none. Keep it: a level with `PHASER: true`, gun pods, or any weapon-creator gun places at least one `type: 'boarder'` home per `boarderWaves` trigger, each over a deck at or past its release line. Wave triggers with no homes are the failure — Level 24 shipped three triggers, PHASER, and pods with zero boarders, a gun with nothing to shoot until the boss. A shootable finale boss alone does not satisfy this; the route needs targets before the arena. Conversely, a PHASER-off level keeps the token wave trigger only: boarders without a gun are unkillable, so no boarder homes and no pods.

**Pressure stacks past the opener.** One hazard at a time is the teach beat, not the level: past the opener, every act overlaps two threat types (boarders under a timed beam, a drone lane over a crusher deck, a bonk chain beside a patrol), so the player answers two questions at once. A route of isolated singletons — one laser, a long walk, one drone — is a draft however pretty the shots. The Fun dimension scores decisions per minute; a second threat the player can read is difficulty, a second threat they cannot is `cheap` — keep every tell intact while stacking.

Banned shortcuts (each is an automatic critic flaw, not a style choice): palette swap over a copied route; one deck texture end to end; an upper route with nothing on it; a finale with no pressure; a beam that guards only one of two routes to the crown; a themed enemy that is a renamed generic hazard with generic behaviour; a PHASER level with no boarder homes on the route; a post-opener act with a single isolated threat; a contra level whose action all happens at one height; a tier the gun cannot reach and nothing else answers (boarders parked where no bolt, bonk, or drop-in can touch them); a split where one branch is strictly safe, empty, or shorter with no cost.

**Skeleton diversity is measured, not vibes.** The critic compares your sorted deck x sequence and world width against every shipped level (`skeleton-rhyme`, similarity ≥0.85 at the same width and deck count). Levels 17/19/20 shipped the same 6000px, 14-deck x-list under three paints and scored novelty 1.1–1.6 for it. Never start from a shipped level's deck list — not even as a "structure reference." Pick the world width from the Topology Fingerprint (towers are short and tall, gauntlets are short and dense, traverses earn their length), then lay decks from the height-profile sketch. In a batch, no two levels share a width, a deck count, and a gravity band.

**Finale pressure must photograph.** The beat sheet freezes the world, so a lone timed vertical laser caught off-phase reads as an empty crown deck and draws `sleeping-finale` no data argument can rebut (the critic flags this as `finale-invisible`). The finale contract: within the crown frame, place at least one pressure a frozen still can show — a body hazard patrolling the crown deck itself (roller, drone, crusher), a horizontal beam, a mostly-on beam (duty ≥0.6), or two staggered beams that cover each other's off-phases — on every route to the crown. A timed laser 250px away plus a distant roller does not meet it.

Copy chosen platform and prop paints into `SpriteFactory.js` and register them. Point platforms at those keys. Decorations go in `props` and must not collide. Hitboxes stay on the opaque deck, not on a transparent margin. Place every boarder home over a deck: a boarder spawned over a gap falls out of the world, and on a `CROWN_SHIELD` level that free kill opens the gate early. Checkpoints respawn onto solid decks, never over gaps. Timed-laser `offDuration` stays at 800ms or more: the pilot's walk-through gate needs `span/160*1000+350`ms of off-window (~762ms for a 66px beam span), and shorter windows hold it forever instead of failing loudly.

The route has to be finishable with normal jumps. Gaps, moving platforms, and hazards still need a landing. The crown sits on a reachable deck. A new end-of-level idea uses [the crown encounter skill](../boss-creator/SKILL.md). Updating an old level does not replace its last stretch unless the user asked.

If the new art needs a hazard the registry cannot express, add an `enemies/<name>.js` spawn function, register it in `enemies/index.js`, and clean it up on retry. Do not invent a config field that nothing reads.

## Stacked tiers and split paths (contra-style levels)

Contra-style means run-and-gun pressure at several heights, not a platformer with a gun. It applies to campaign levels 8+, to any news level whose brief declares `Combat profile: contra`, and to any standalone level that declares the same profile in its build report. Contra levels run on stacked **tiers** — distinct height bands the player can stand on, fight from, and travel between — with routes that split across tiers and rejoin. One flat line with a shelf is a platformer, not contra.

**Engine boundary — design inside it, never brief past it.** The phaser aims Contra-style (`aimVector` in `GameUtils.js`): forward, up, diagonal-up while moving, and down/diagonal-down while airborne; fan weapons spread perpendicular to the aim. There is no crouch or prone — aiming down on the ground still fires forward — and no config field adds finer aim angles. Cross-height action therefore comes from aim plus position: shooting up or diagonally at the tier above, dropping fire onto the tier below, firing a fan from range, jumping to align a shot, standing on the target's tier, or bonking from above. A brief that needs finer aim than those directions (tracking shots, free-angle fire) is an engine change — name it as such and stop; do not encode it in level data and hope. Platforms are solid from all sides (no one-way or jump-through decks), and the chicken has a double jump whose second stage is the jetpack.

**Name the tiers in the build report first.** Add a Height & Path Map before authoring decks: one row per tier (name, deck-top y band, how the player gets on and off it, what fights or pays there, where it rejoins), plus the jump-rise budget for the level's gravity. Tiers are bands, not single decks: decks within ~40px of each other are one tier with steps; a new tier starts where the player must commit to a climb, a drop, or a lift ride to change height.

| Tier spacing (deck-top to deck-top)   | Reads as                          | Rule                                                                                                                                                      |
| ------------------------------------- | --------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| < 56px                                | step, not a tier                  | Never count it as a second line; the reachability test does not either.                                                                                   |
| 56px up to single-jump rise `R`       | close tier                        | Freely interchangeable in combat; the default spacing for stacked gun lines. `R = floor(330² / 2g) − 5` (≈176px at gravity 300, less when gravity rises). |
| `R` up to roughly `2R`                | tall tier                         | Needs stairs, staggered hops, a moving lift/tram, or a deliberate double jump. Never the only mandatory climb until the double jump has been taught.      |
| Drop of any depth                     | descent line or pit tier          | Always legal (no fall damage); the landing must be readable and survivable — pair deep drops with the `blind-landing` check, not with faith.              |
| Underside clearance under a high tier | at least 56px over the tier below | The chicken is 32px tall; the low route must be runnable underneath, not a crawl gap.                                                                     |

How many tiers: at least **two** full tiers for the whole level, and at least **three** distinct standable heights (counting a pit or shaft line) in at least one act — two is the floor the tests check, three is where contra play starts. Raise `WORLD_HEIGHT` to fit them (shipped worlds run 700–900px; the camera follows vertically and backgrounds bake to the level's height), and re-place the kill zone, checkpoints, and crown for the taller world instead of stretching one floor plan. In a batch, siblings differ in tier count or tier spacing, not only in paint.

**Actions happen at every height.** Each tier carries its own verbs; a tier the player only crosses is a corridor, not a route. Build from:

| Height action           | How it plays in this engine                                                                                                                         | Placement rule                                                                                                                                                                         |
| ----------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Same-tier gunfight      | Boarders on the player's own deck, faced and shot horizontally.                                                                                     | The core contra verb; every tier that hosts boarders gives them a deck, a wave release at or past their x, and landing run to fight on.                                                |
| Aim across tiers        | Holding ↑/W while firing shoots up or diagonal-up at the tier above; airborne ↓/S drops fire onto the tier below.                                   | The target must be answerable from a standable firing position — check the actual aim lines, not just deck distance; overhead targets need headroom to stand and aim, not a crawl gap. |
| Fan across tiers        | Scatter/Tempest/Comet/Hail spread fans perpendicular to the aim and clips the next tier at distance.                                                | Only counts past ~300px of horizontal range; at point blank the fan is still narrow. Give the shooter a standoff lane, and put the pod where the fan starts paying.                    |
| Jump-and-fire alignment | The player jumps (or double-jumps) to bring the bolt line onto a higher or lower target mid-arc.                                                    | Target tier within jump reach of the firing deck; never demand pixel-perfect apex shots on the mandatory route.                                                                        |
| Drop-in attack          | Dropping from a high tier onto a low fight — shooting on the way down, bonking, or landing behind a patrol.                                         | The drop needs a visible landing and an exit; a drop that is also the only way back up is a trap, not a route.                                                                         |
| Hold the high ground    | An upper tier with its own boarders, drone, pod, or rescue, fought for and defended while the low route presses underneath.                         | The high tier must be threatened on its own level (stationed wave, drone lane), not a safe balcony over someone else's fight.                                                          |
| Fight under an overpass | The low route runs under a deck while hazards work above and below (drones crossing the gap, crushers or drips through it, boarders on both lines). | Keep hazard lanes clearing every overlapping deck by 8px+, and keep the underpass readable — props and background mass off the firing line.                                            |
| Cross-height mover      | A lift, tram, or moving deck carries the player between tiers while boarders or beams press the ride.                                               | The mover is a route edge in the graph, not decoration; drones clear the rider zone, and the landing tier is fought over, not empty.                                                   |
| Vertical set piece      | A shaft, tower, trench, or stair fort where the route itself climbs or plunges through tiers under fire.                                            | One signature set piece per contra level (bridge, shaft, stair, trench, tower) that no sibling repeats; the climb is pressured, not a lift lobby.                                      |

**Split paths, then rejoin.** In at least one act the route forks across heights — low road against high road — and both branches rejoin at a checkpoint, a gate, or the finale approach. Each branch has a distinct cost and payoff: the low road is faster under heavier ground fire; the high road is exposed to drones and beams but holds the pod, rescue, or bypass. A branch that is strictly safer, emptier, or shorter is banned (see Banned shortcuts). Optional tiers off the main line hold a pod, rescue, or time-saving bypass and rejoin without backtracking through a hazard lane. Every route to the crown — low, high, and mover — meets the finale pressure; a gate or beam that covers only one height is decorative.

Geometry and safety rules (the shipped contract, now per tier):

- Clearance: at least 56px between an upper deck's underside and the lower deck's top (the chicken is 32px tall).
- Climbs: every mandatory upward move fits a normal single jump for the level's gravity (rise ≤ v²/2g − 5px), except a taught double-jump, lift, or stair climb named in the Height & Path Map. Drops can be any depth; there is no fall damage.
- No jump-through: bodies are solid from all sides, so climbs need stairs, staggered overlaps, or side gaps — never a jump up through a deck. Target decks give 190px+ of landing run; any touch or overlap plus a single-jumpable rise connects.
- Boarders fight from their own tier: keep shelves ≥120px above patrol decks (boarder hop peaks ~112px) unless a wave is stationed up top on purpose — deliberate high-tier boarders are a feature now, accidental hop-overs are not. Boarders hop only ~48px of clearance and steer on decks; never park them where their hop cannot follow the route they guard. Every boarder tier still satisfies the wave rule: at least one `type: 'boarder'` home per `boarderWaves` trigger, over a deck at or past its release line.
- Hazard lanes stay clear across heights: emitters, patrols, and slam footprints must clear every overlapping deck by 8px or more. Drones are the cross-height threat (they patrol in x and y and ignore gravity); rollers, rovers, and crushers belong to one tier and must not read as threatening another.
- A stacked line needs ≥32px of shared run with 56–200px of vertical separation from its neighbor; anything less is a step, not a line. A third tier may sit outside that band only as a tall tier with its own climb (stairs, lift, or taught double jump) named in the map.
- Reachability: every deck joins one directed graph from the opener. An edge exists when decks touch or overlap with a single-jumpable rise (up) or any drop (down), or the side gap is ≤260px with a single-jumpable rise. `tests/contra-levels.test.cjs` walks the graph; new decks fail there until the graph connects. The test proves one stacked pair; the three-height and split-path requirements above are yours to prove in the build report (tier rows with deck coordinates) and in play, one branch at a time.
- Two deck textures per level minimum, and a third read where a third tier exists: tiers never share one paint end to end. The accent inverts the main deck (pale edge on dark body, or dark on pale) so each route reads at a glance, and height reads before the player jumps — a tier change is visible in silhouette, not discovered by collision. Copy-paste skeletons across levels are banned: each contra level carries one signature solid set piece (bridge, shaft, stair, trench, or tower) that no sibling level repeats.
- Checkpoints stand before gates and at path rejoins: never inside on/off beam timing, never under a drone or dust devil lane, and 150px+ clear of every boarder home. A respawn must give one safe breath, on the tier the checkpoint names. Props stay out of crusher slam footprints (40px+); drones clear lift rider zones by sprite. `tests/level-polish.test.cjs` locks all four.
- Every shelf pays or threatens: a bypass around trouble, a drone, a bonk, or a stationed runner — never an empty plank.
- Finale beams cover every route to the crown at every height: if a lift or shelf lets the player duck the band, the beam is decorative and must grow or move.

**Contra difficulty holds the shipped band.** Level 24 shipped contra-style at 1.7 hazards per 1000px with 4 hazard types, and the critic pilot cleared it in 44s with zero deaths — too easy. New contra levels ship ≥2.2 dynamics per 1000px of world width with ≥5 hazard types, the floor of the shipped 8–16 band (2.30–2.83, 5–7 types); record both numbers in the build report. Count cross-height pressure honestly: a drone that crosses two tiers is one dynamic, not two, and density parked on a tier the route never visits does not count. Past the opener, acts overlap threats across heights as well as along the run (boarders below under a drone lane, a high-tier wave answering a low push) so the player reads two heights at once — with every tell intact. The boss arena keeps overlapping pressure besides the boss itself — a static hazard in the arena or summon adds (every shipped boss except the introductory Broodmother has one): a clean 1v1 duel in an empty room is not a contra finale.

## Verify — the critic run is part of done

Update tests that assert the level list, music ids, or background type when those lists grow. Keep the old levels covered. Run `npm test`.

If registry growth trips the repo's max-lines gate (a longer `LEVEL_IDS` table or `create()` pushing a function over the lint cap), extract module-scope consts (id tables, plate maps) rather than splitting behavior — the table growth is the cause, not the logic around it.

Play `http://127.0.0.1:3000/?level=N` from the start to the crown. Confirm the selected paints are on screen, platforms match their art, a bonk works if you placed one, pause and a death retry, and the next level or the final clear. Check an earlier level if you touched shared builder or background code. A debug skip only proves the handoff. On a contra level, play **every branch and tier** the Height & Path Map names — low road and high road, each drop-in and mover ride, and the finale approached from each height — and record per-branch outcomes (clear, deaths, what pressured you); a crown reached on one branch proves nothing about the others, and an unplayed branch is reported as unverified, not assumed fine.
**Run the Signature proof.** Execute the canvas's bypass test: attempt the crown while deliberately skipping the signature (no bonk, no lift ride, no cargo). Record the outcome (blocked / rerouted / clean clear) plus the observable counts from the honest run (bonks, lift contact, cargo state) in the build report. A mandatory claim with a clean bypass is reclassified optional on the spot — fix the brief, the instructions, and the canvas in the same change, not just the fact→mechanic table. Generated background plates also get a full-scroll seam check (walk the camera the whole width once): a visible plate-edge join on the route is an integration defect, not a style note.

**Then run the critic. The level is not done without it:**

```bash
npm run critic:level -- <id>          # news levels: NEWS_BRIEF=<brief> npm run critic:level -- <id>
node scripts/boss-review.mjs <id>     # when the level has a crown encounter (8-16 pattern)
```

The run captures pilot telemetry and a screenshot beat sheet, sends the screenshots to the panel as image evidence, and writes `docs/level-reviews/level-<id>.md`. On **iterate**, fix only the top contracted fix from the report's `## Fix contract` (`fixes[0]` in the JSON: flaw, evidence, owner, `smallestFix`, `recheck`) — one fix per loop — then re-run the _full_ critic, never just the segment you changed and never the lower-ranked fixes in the same loop. On **rework**, return to the three artefacts with a new fingerprint; do not tune. Maximum three loops, then hand the report to the user. Without a TypeSafe key the run returns mechanical pass at best: record `critic: mechanical-only` and do not call the level shipped. News levels also need the fidelity gate in the same report (story elements shown, no contradicted fact→mechanic row, no `needs-human` left unconfirmed).

Write `docs/level-builds/<level-id>.md` (create the folder if it is missing) with the Novelty Ledger, Signature Mechanic Canvas, Topology Fingerprint and the two killed layouts, the Height & Path Map for contra levels (tier rows with deck-top y bands and coordinates, climb type per tier change, branch costs and payoffs, per-branch play outcomes), the assumptions, the selection paths, texture keys, hazard types used, files changed, the play URL, the critic report link with both verdicts quoted, and what you could not verify. Name concept actors separately from the hazards that actually spawn. A build report with no critic link is incomplete and the level stays a draft.
